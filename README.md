# Deck Pamphlets

Make a guide for a Commander deck and save it as a PDF to show other players before and during a game.

Open it: https://villadsrasmussen-hue.github.io/deck-pamphlets/

- Paste a decklist (Aetherhub, Deckstats and similar text exports). It is sorted by type, then mana value high to low, then A to Z. Card data and images come from Scryfall.
- Write about the deck, show its combo lines and a top 10 of its cards.
- Press Save as PDF and choose "Save as PDF" as the printer.

Pamphlets are saved in the browser you make them in. Use Save to file / Open file to move one to another device.

Unofficial fan content. Card images and data © Wizards of the Coast, via Scryfall.
